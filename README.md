# Bijuterii Handmade & Mărturii (PWA)

Catalog web static cu suport Progressive Web App (`manifest.json` și `sw.js`) pentru prezentarea produselor de bijuterii handmade și mărturii din pietre semiprețioase.

## Structură

- `index.html` — pagina principală și stilizare/interacțiune client-side
- `manifest.json` — manifest PWA pentru instalare ca aplicație standalone
- `sw.js` — Service Worker pentru cache offline (`bijuterii-cache-v2`)
